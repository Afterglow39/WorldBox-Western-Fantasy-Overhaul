一款為 **WorldBox** 製作的繁體中文文明命名重構模組。

本模組並非單純將英文名稱翻譯成中文，而是根據每個種族與生物的：

- 種族簡介
- 亞種說明
- 外觀特徵
- 建築風格
- 生態與習性
- 奇幻作品中的常見形象
- 遊戲內的文明定位

重新設計完整且彼此一致的中文命名體系。

目標是讓每個文明不只是「擁有中文名稱」，而是真正呈現出屬於自己的歷史、文化與生活方式。

---

## 主要內容

每個已支援的文明會依照實際情況接入多項專屬命名，包括：

- 人物姓名
- 人物稱號
- 城市與村莊
- 王國與政權
- 氏族
- 家庭
- 亞種
- 文化
- 宗教
- 語言
- 軍隊
- 同盟
- 戰爭
- 格言
- 書籍
- 其他文明相關名稱

不同種族不會只共用同一套通用詞庫。

例如精靈、矮人、獸人、人類及各種動物文明，都會根據自身特色使用不同的語言風格、社會制度與命名方式。

---

## 文明重構方式

本模組會先確認一個物種的文明核心，再將相同的文明概念延伸到人物、城市、國家、宗教、文化與其他系統。

例如：

- 人類：選擇、適應、野心、親情與錯誤
- 精靈：記憶、共生、季節、古語與守望
- 矮人：精確、鍛造、傳承、山岩與恩怨
- 獸人：崛起、力量、生存、忠誠與征服

因此名稱不會只是不斷堆疊「月、星、鐵、血、王」等種族關鍵字，而是盡量讓整個文明擁有一致且自然的世界觀。

---

## 四大主要種族

人類、精靈、矮人與獸人擁有較完整的原作資料、奇幻作品參考與玩家認知，因此進行了額外問卷、分類與多版本重製。

這四個主要種族的內容精細度與詞庫規模，大約會是部分其他文明的二至三倍。

其中人類人物名稱目前大致為：

- 普通姓名：73%
- 帶稱號姓名：27%
  - 其中負面或滑稽綽號：約占全部結果的 2%
  - 稀有完整故事稱號：約占全部結果的 3%

稀有內容不會大量出現，避免每個普通居民都像傳說英雄。

## 支援範圍

目前已確認約有五十多種文明物種、動物變體與特殊生物接入中文化系統。

新版完整文明框架下，一個種族最多可能使用約 56 份相關資料文件。

部分較早期製作的文明使用約 28 份資料文件，但已抽查並重新優化多個命名過於老舊或風格不一致的種族。

### 普通動物開智

普通動物觸碰開智石後，即使沒有轉換成特殊智慧變體，也能接入目前的文明中文化系統。

普通動物會保留：

- 自然動物風格的家庭
- 動物亞種
- 原本的物種名稱

而建立文明後的其他內容，例如城市、王國、文化、語言與軍隊，則會接入對應文明命名。

### 特殊生物建立文明

部分原本沒有智慧的生物，在修改亞種或獲得智慧後也可能建立文明，例如：

- 惡魔
- 天使
- 冰魔
- 元素生物
- 特殊怪物
- 其他可文明化生物

只要目前能正確確認其遊戲 ID，模組就會盡量為其提供家庭、亞種及完整文明內容。

### 成長前後形態

部分生物會由幼體或前身形態長成另一種文明生物，例如：

- 花苞 → 花靈
- 史摩爾 → 糖果人
- 水晶之劍 → 水晶魁儡
- Garl → 蒜頭人
- 酸性斑點 → 酸性紳士

前身與成年文明形態會盡量使用不同且合理的家庭與亞種資料，避免直接混用錯誤命名。

## 文化名稱延遲說明

目前因 WorldBox 的文化集合無法在模組載入初期穩定取得，主控台可能會出現類似以下警告：

```text
[西方奇幻文明重構]：[CULTURE] 尚未在 World.world 找到文化集合；
將持續低頻重試，不影響模組其他功能。
```

這不是致命錯誤，也不代表模組載入失敗。

當物種建立村莊並確認世界資料已完成生成後，模組會延遲約 30 幀再次取得文化資料，並將文化修改為正確名稱。

在文化名稱正式更新前，目前觀察到村莊與其他主要命名仍可正常運作。

## 已知差異與注意事項

本模組經歷了超過一百次內部修改與測試版本。

因為不同種族的製作時間與框架版本不同，少部分早期文明與新版文明之間，可能仍存在：

- 詞庫數量差異
- 名稱格式差異
- 世界觀精細度差異
- 少量較舊的命名風格

目前已針對多個較明顯的舊文明進行新版優化。

實際遊玩時，若發現某個種族的名稱特別突兀、錯誤套用其他種族資料，或仍出現未中文化內容，歡迎回報。

由於不同文明主要依照獨立 ID 分流，因此通常不容易互相污染。

如果某個未支援生物出現了名稱，它可能正在使用原始框架中保留的舊版通用漢化資料。

## 語言

目前所有新製作內容皆以 **繁體中文** 為主。

原因包括：

- 作者日常使用繁體中文
- 開發與測試環境使用繁體中文
- 舊版內容審查與 AI 輔助溝通皆以繁體中文進行

若模組發布後有足夠多簡體中文玩家回饋與需求，未來可以再討論製作簡體中文版本。

---

## 隨機性

模組增加了隨機變數與種子更新機制。

在以下情況中，命名結果會重新取得較完整的隨機體驗：

- 重新啟動遊戲
- 切換地圖
- 建立新世界
- 新文明出現
- 新角色或新政權生成

因此即使使用相同物種，也不會總是重複出現完全相同的一小批名稱。

## 安裝方式

1. 安裝與目前 WorldBox 版本相容的 NeoModLoader。
2. 下載本模組壓縮檔。
3. 解壓縮後，將完整模組資料夾放入 WorldBox 的 `Mods` 資料夾。
4. 啟動遊戲並確認模組已成功載入。
5. 建議使用新世界測試文明、家庭、文化與亞種命名。

更新模組時，建議先刪除舊版本資料夾，再放入新版。

請勿直接覆蓋舊資料夾，避免已刪除的歷史檔案或舊詞庫殘留。

## 回報問題

目前模組由一人製作，能進行的實機測試時間有限。

若遇到以下情況，請提供截圖、物種名稱及發生方式：

- 名稱沒有中文化
- 物種吃到其他文明的名稱
- 家庭或亞種沒有生效
- 城市、王國或文化名稱不正確
- 開智前後出現異常
- 主控台出現與本模組有關的紅色錯誤
- 某種族的名稱風格特別突兀

可透過以下方式回報：

- GitHub Issues
- Steam 留言
- 電子郵件
- 作者提供的其他聯絡方式

## 自訂與修改

本模組大部分文字資料存放於 JSON 與 `word_libraries` 中，格式相對簡單。

你可以自行：

- 修改不喜歡的名稱
- 增加新的詞彙
- 調整生成比例
- 為其他物種新增命名
- 修改文明風格

不熟悉 JSON 也可以使用文字編輯器，或詢問 AI 協助理解檔案格式。

很歡迎玩家製作自己的改版或額外內容。

若你完成了更好的詞庫或新文明內容，也很希望能分享給我試玩，因為作者本人同樣想玩到其他玩家創作出的更完整世界，哈哈。
