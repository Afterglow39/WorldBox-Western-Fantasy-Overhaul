一款為 **WorldBox** 製作的繁體中文文明命名重構模組。

本模組並非單純將英文名稱翻譯成中文，而是根據每個種族與生物的：

- 種族簡介
- 亞種說明
- 外觀特徵
- 建築風格
- 生態與習性
- 奇幻作品中的常見形象
- 遊戲內的文明定位

重新設計完整且彼此一致的中文命名體系。

目標是讓每個文明不只是「擁有中文名稱」，而是真正呈現出屬於自己的歷史、文化與生活方式。

---

## 主要內容

每個已支援的文明會依照實際情況接入多項專屬命名，包括：

- 人物姓名
- 人物稱號
- 城市與村莊
- 王國與政權
- 氏族
- 家庭
- 亞種
- 文化
- 宗教
- 語言
- 軍隊
- 同盟
- 戰爭
- 格言
- 書籍
- 其他文明相關名稱

不同種族不會只共用同一套通用詞庫。

例如精靈、矮人、獸人、人類及各種動物文明，都會根據自身特色使用不同的語言風格、社會制度與命名方式。

即使是尚未建立專屬資料、甚至無法確認 ID 的新物種，也會由完整保底系統接入符合本模組世界觀的文明命名。

---

## 文明重構方式

本模組會先確認一個物種的文明核心，再將相同的文明概念延伸到人物、城市、國家、宗教、文化與其他系統。

例如：

- 人類：選擇、適應、野心、親情與錯誤
- 精靈：記憶、共生、季節、古語與守望
- 矮人：精確、鍛造、傳承、山岩與恩怨
- 獸人：崛起、力量、生存、忠誠與征服

因此名稱不會只是不斷堆疊「月、星、鐵、血、王」等種族關鍵字，而是盡量讓整個文明擁有一致且自然的世界觀。

---

## 四大主要種族

人類、精靈、矮人與獸人擁有較完整的原作資料、奇幻作品參考與玩家認知，因此進行了額外問卷、分類與多版本重製。

這四個主要種族的內容精細度與詞庫規模，大約會是部分其他文明的二至三倍。

其中人類人物名稱目前大致為：

- 普通姓名：73%
- 帶稱號姓名：27%
  - 其中負面或滑稽綽號：約占全部結果的 2%
  - 稀有完整故事稱號：約占全部結果的 3%

稀有內容不會大量出現，避免每個普通居民都像傳說英雄。

## 支援範圍

目前已確認約有五十多種文明物種、動物變體與特殊生物接入中文化系統。

新版完整文明框架下，一個種族最多可能使用約 56 份相關資料文件。

部分較早期製作的文明使用約 28 份資料文件，但已抽查並重新優化多個命名過於老舊或風格不一致的種族。

目前整體命名系統分為四個層級：

### 1. 專屬文明資料

已完成重製的文明會使用自己的專屬人物、家庭、氏族、城市、王國、文化、宗教、語言、軍隊、格言、書籍與亞種資料。

例如人類、精靈、矮人、獸人，以及大部分已完成重構的動物文明與特殊智慧生物，都會依照各自的世界觀使用獨立命名。

### 2. 動物名稱資料庫

部分生態、體型或定位相近的動物，會共用同一套**個體名稱詞庫**。

例如部分小型肉食動物、草食動物或生活方式相近的物種，可能使用相同的個體名稱生成規則。

這一層只影響：

- 個體名稱

家庭、亞種、城市、王國、文化、語言與其他文明資料，仍會依照各物種或對應文明系統獨立生成。

這樣能讓相近動物維持一致的命名風格，也方便未來新增相同類型的物種時直接接入現有名稱資料庫。

### 3. 小型生物共用文明資料

部分體型較小、文明表現與生活尺度較接近的生物，會保留各自的物種名稱、個體名稱、家庭與亞種，但在建立文明後，共用一套適合小型生物的中性文明命名。

目前包含：

- 鴕鳥
- 蜜蜂
- 蝴蝶
- 蚱蜢
- 蒼蠅
- 普通甲蟲

它們共用的文明內容包括：

- 城市與村莊
- 王國與政權
- 氏族
- 文化
- 宗教
- 語言
- 軍隊
- 同盟
- 戰爭
- 格言
- 書籍

這套命名主要使用草原、巢穴、晨露、微光、羽翼、蟲殼與群落等意象，避免出現過度宏偉或明顯只適合大型種族的名稱。

這並不代表上述生物屬於同一個種族，而是依照相近的文明規模與生態表現，共用一套合理的命名風格。

### 4. 未知物種完整保底資料

任何沒有命中既有專屬文明，或目前無法確認、掃描其遊戲 ID 的物種，都會自動接入另一套完整的中性文明命名。

例如：

- Bitba
- 喪屍
- 腫瘤怪物
- 藍色螞蟻
- 紅色螞蟻
- 黑色螞蟻
- 綠色螞蟻
- 未來新增且尚未建立專屬資料的物種

即使無法辨識其真實 ID，只要進入模組已接管的命名流程，就會自動取得：

- 人物姓名與稱號
- 家庭與亞種
- 氏族
- 城市與村莊
- 王國與政權
- 文化、宗教與語言
- 軍隊、同盟與戰爭
- 格言與書籍

這套資料採用偏灰境、暮影、荒巢、深穴與殘生的中性西方奇幻風格，能同時容納怪物、未知生物與特殊文明。

未來 WorldBox 若新增新的可文明化生物，只要沒有命中既有專屬文明，也會自動由這套保底系統接住，而不會掉回英文、空白或舊版通用資料。

### 普通動物開智

普通動物觸碰開智石後，即使沒有轉換成特殊智慧變體，也能接入目前的文明中文化系統。

普通動物會保留：

- 自然動物風格的家庭
- 動物亞種
- 原本的物種名稱

而建立文明後的其他內容，例如城市、王國、文化、語言與軍隊，則會接入對應文明命名。

### 特殊生物建立文明

部分原本沒有智慧的生物，在修改亞種或獲得智慧後也可能建立文明，例如：

- 惡魔
- 天使
- 冰魔
- 元素生物
- 特殊怪物
- 其他可文明化生物

若能確認遊戲 ID，會優先建立專屬命名；即使無法確認或掃描 ID，也會由「未知物種完整保底資料」自動接入全套文明中文化。

### 成長前後形態

部分生物會由幼體或前身形態長成另一種文明生物，例如：

- 花苞 → 花靈
- 史摩爾 → 糖果人
- 水晶之劍 → 水晶魁儡
- Garl → 蒜頭人
- 酸性斑點 → 酸性紳士

前身與成年文明形態會盡量使用不同且合理的家庭與亞種資料，避免直接混用錯誤命名。

## 文化名稱延遲說明

目前因 WorldBox 的文化集合無法在模組載入初期穩定取得，主控台可能會出現類似以下警告：

```text
[西方奇幻文明重構]：[CULTURE] 尚未在 World.world 找到文化集合；
將持續低頻重試，不影響模組其他功能。
```

這不是致命錯誤，也不代表模組載入失敗。

當物種建立村莊並確認世界資料已完成生成後，模組會延遲約 30 幀再次取得文化資料，並將文化修改為正確名稱。

在文化名稱正式更新前，目前觀察到村莊與其他主要命名仍可正常運作。

## 未知物種保底系統

從 v1.0.5 開始，模組不再需要逐一列出所有未知物種 ID。

例如 Bitba、喪屍、腫瘤怪物與四種螞蟻，即使無法確認真實 ID，只要進入模組已接管的命名流程，就會自動使用「未知物種」完整文明資料，包括：

- 人物姓名與稱號
- 家庭與亞種
- 氏族
- 城市與村莊
- 王國與政權
- 文化、宗教與語言
- 軍隊、同盟與戰爭
- 格言與書籍

這套資料採用偏灰境、暮影、荒巢、深穴與殘生的中性西方奇幻風格，可容納不同類型的未知生物，又不會明顯偏向單一種族。

未來 WorldBox 若新增新的可文明化生物，只要沒有命中既有專屬文明，也會自動由這套保底系統接住。

## 已知差異與注意事項

本模組經歷了超過一百次內部修改與測試版本。

因為不同種族的製作時間與框架版本不同，少部分早期文明與新版文明之間，可能仍存在：

- 詞庫數量差異
- 名稱格式差異
- 世界觀精細度差異
- 少量較舊的命名風格

目前已針對多個較明顯的舊文明進行新版優化。

實際遊玩時，若發現某個種族的名稱特別突兀、錯誤套用其他種族資料，或仍出現未中文化內容，歡迎回報。

已完成的文明會優先使用獨立專屬路由；小型生物與未知物種則分別使用各自的共用文明資料，因此通常不容易互相污染。

若某個新物種尚未建立專屬資料，它會自動使用未知物種保底命名，而不是回到原始框架中的舊版通用漢化。

## 語言

目前所有新製作內容皆以 **繁體中文** 為主。

原因包括：

- 作者日常使用繁體中文
- 開發與測試環境使用繁體中文
- 舊版內容審查與 AI 輔助溝通皆以繁體中文進行

若模組發布後有足夠多簡體中文玩家回饋與需求，未來可以再討論製作簡體中文版本。

---

## 隨機性

模組增加了隨機變數與種子更新機制。

在以下情況中，命名結果會重新取得較完整的隨機體驗：

- 重新啟動遊戲
- 切換地圖
- 建立新世界
- 新文明出現
- 新角色或新政權生成

因此即使使用相同物種，也不會總是重複出現完全相同的一小批名稱。

## 安裝方式

1. 安裝與目前 WorldBox 版本相容的 NeoModLoader。
2. 下載本模組壓縮檔。
3. 解壓縮後，將完整模組資料夾放入 WorldBox 的 `Mods` 資料夾。
4. 啟動遊戲並確認模組已成功載入。
5. 建議使用新世界測試文明、家庭、文化與亞種命名。

更新模組時，建議先刪除舊版本資料夾，再放入新版。

請勿直接覆蓋舊資料夾，避免已刪除的歷史檔案或舊詞庫殘留。

## 回報問題

目前模組由一人製作，能進行的實機測試時間有限。

若遇到以下情況，請提供截圖、物種名稱及發生方式：

- 名稱沒有中文化

- 家庭或亞種沒有生效
- 城市、王國或文化名稱不正確
- 開智前後出現異常
- 主控台出現與本模組有關的紅色錯誤
- 某種族的名稱風格特別突兀

可透過以下方式回報：

- GitHub Issues
- Steam 留言
- 電子郵件
- 作者提供的其他聯絡方式

## 自訂與修改

本模組大部分文字資料存放於 JSON 與 `word_libraries` 中，格式相對簡單。

你可以自行：

- 修改不喜歡的名稱
- 增加新的詞彙
- 調整生成比例

不熟悉 JSON 也可以使用文字編輯器，或詢問 AI 協助理解檔案格式。
